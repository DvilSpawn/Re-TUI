# JetBrains Mono Nerd Font Regular

Bundled asset: `app/src/main/assets/JetBrainsMonoNerdFont-Regular.ttf`.
Unmodified upstream font: JetBrains Mono 2.304, patched by Nerd Fonts v3.5.1.
Font SHA-256: `1c680e8cde9fcf8b88a5605ce8d1fb94dd3fb15841f7ca7bf4c55664855e5611`.

Release: https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1
Archive: https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/JetBrainsMono.tar.xz
Archive SHA-256 (verified against GitHub release metadata):
`04d5e8f903693f9dd13e16f867e994834e681eb3c72c0d337a770dcda09010cf`.

The font remains OFL-1.1 licensed, not relicensed under the Launcher's GPL.
The upstream font patch adds icon glyphs; Re:TUI makes no further modifications.
The name is upstream's regular Nerd Font variant, not its Propo or Mono-icon-width variants.
